# WeatherMonitor

Приложение для мониторинга погоды с использованием WeatherAPI.com.

## 📋 Описание

WeatherMonitor — это веб-приложение на Blazor, которое отображает текущую погоду, почасовой прогноз и прогноз на 3 дня для заданного местоположения. Приложение использует MediatR для обработки запросов, AutoMapper для маппинга данных и HttpClient для взаимодействия с внешним API.

## 🎨 Дизайн

Макет пользовательского интерфейса был разработан при помощи искусственного интеллекта. Стек технологий включает:

- **Blazor** — интерактивный веб-фреймворк
- **CSS** — кастомные стили с эффектами размытия (backdrop-filter)
- **Адаптивность** — поддержка мобильных устройств

## 🚀 Технологии

- **.NET 8** — платформа разработки
- **Blazor Server** — интерактивный рендеринг на сервере
- **MediatR** — реализация паттерна Mediator
- **AutoMapper** — преобразование DTO в модели данных
- **xUnit** — тестирование

## ⚙️ Конфигурация

### appsettings.json

```json
{
  "WeatherApi": {
    "Lat": 55.7558,
    "Lon": 37.6173,
    "ApiKey": "YOUR_API_KEY_HERE"
  }
}
```

Для работы приложения необходимо получить API ключ на [WeatherAPI.com](https://www.weatherapi.com/).

## 🧩 Основные компоненты

### Home.razor
Главный компонент приложения, который:
- Отображает состояние загрузки
- Показывает текущую погоду
- Отображает почасовой прогноз
- Выводит прогноз на 3 дня
- Обрабатывает ошибки

### HourItem.razor
Компонент для отображения отдельного часа в почасовом прогнозе.

## 🔧 Установка и запуск

1. **Клонирование репозитория**
```bash
git clone https://github.com/yourusername/WeatherMonitor.git
cd WeatherMonitor
```

2. **Настройка API ключа**
   - Получите API ключ на [WeatherAPI.com](https://www.weatherapi.com/)
   - Замените `ApiKey` в `appsettings.json`

3. **Запуск приложения**
```bash
dotnet restore
dotnet run --project WeatherMonitor.Web
```

4. **Откройте браузер**
   - Перейдите по адресу, указанному в логах

## 🧪 Тестирование

Для запуска тестов:
```bash
dotnet test WeatherMonitor.Tests
```

### Тесты включают:
- **AutoMapperTests** — проверка конфигурации маппинга
- **UtilitiesTests** — тестирование вспомогательных методов
- **WeatherHandlersTests** — тестирование обработчика погоды

## 🔌 API интеграция

Приложение использует [WeatherAPI.com](https://www.weatherapi.com/) для получения данных о погоде:

```
GET https://api.weatherapi.com/v1/forecast.json?key=API_KEY&q=LAT,LON&days=3
```
